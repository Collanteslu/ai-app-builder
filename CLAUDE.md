# Claude Code — AI App Builder

Este proyecto está configurado para trabajar con **Claude Code** usando el AI App Builder framework.

## Inicio rápido

1. **Edita `stack.md`** — define tu tech stack (qué plataformas, bases de datos, auth, etc.)
2. **Abre Claude Code en esta carpeta**
3. **Cuéntale a Claude qué quieres construir:**
   ```
   "Quiero crear una aplicación para [tu idea]"
   ```

Claude tomará el control y te guiará fase por fase:
- 🔍 **Discovery** — entiender requisitos
- 📋 **PRD** — especificación del producto
- 🏗️ **Architecture** — diseño técnico
- 🎨 **Design** — mockups y UI
- 💻 **Implementation** — código
- ✅ **Testing** — tests y validación
- 📦 **Deployment** — instrucciones para subir a producción

## Skills disponibles

Las skills están en `.claude/skills/`. Claude las cargará automáticamente según lo que necesite.
